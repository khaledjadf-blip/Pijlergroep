# Pijler Groep — Holding Website

Next.js 14 (App Router) · React 18 · TypeScript · Tailwind CSS · Three.js

Marketing site for **Pijler Groep**, the holding behind three operating companies:

- **Verkeersplus Services B.V.** — verkeersplus.nl
- **VCA Veilig & Vakkundig B.V.** — vcaveiligvakkundig.nl
- **Netjes & Klaar B.V.** — netjesenklaar.nl

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content & translations

All site copy lives in `data/site.ts`. Editing there updates the page, sitemap,
metadata, and structured data at once. No text is hard-coded inside components.

## SEO

- Metadata is set in `app/layout.tsx` with Open Graph, Twitter card, and canonical.
- Organization schema (`Organization` + `subOrganization`) is injected as JSON-LD.
- Sitemap and robots are generated by `app/sitemap.ts` and `app/robots.ts`.

## Design system

Design tokens (colors, spacing rhythm) are defined as CSS variables in
`globals.css` and mirrored in `tailwind.config.ts` so both class utilities and
custom CSS stay in sync.

Brand colors:

- Ink / paper base — dark holding anchor
- Brand red `#d4191b` — Verkeersplus
- Brand gold `#c9962e` — VCA Veilig & Vakkundig
- Brand teal `#2f8f83` — Netjes & Klaar

Type pairing:

- **Space Grotesk** — display / headlines
- **Space Mono** — labels / eyebrows
- **Inter** — body copy

## Motion & accessibility

- Scroll-triggered reveals via `IntersectionObserver`, respecting
  `prefers-reduced-motion`.
- Three.js atom uses `requestAnimationFrame`, cleans up on unmount, and skips
  animation when reduced motion is set.
- Semantic HTML, ARIA on decorative elements, keyboard-visible focus states.

## Deploy

Deploys 1:1 to Vercel with zero config. Also runs as any Node.js host with
`npm run build && npm start`.
